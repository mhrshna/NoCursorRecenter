# No Cursor Recenter

Keeps Minecraft from forcing your cursor back to the center when you press the Windows key, switch apps with Alt+Tab, or minimize the game. Also applies when opening menus and inventories. Normal pause behavior stays unchanged.

## Installation

Requires **Minecraft 26.3**, **Fabric Loader 0.19.5 or newer**, and **Java 25 or newer**. Fabric API is not required.

Download the mod JAR and put it in your `.minecraft/mods` folder. Install on the client only; servers do not need it.

## Compatibility

Other mods that change mouse capture or cursor positioning may conflict. Cursor behavior can still depend on the operating system and SDL.
